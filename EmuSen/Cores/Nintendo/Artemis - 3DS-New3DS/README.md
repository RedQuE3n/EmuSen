# Artemis (Nintendo 3DS / New Nintendo 3DS)

Reserved for a future Nintendo 3DS / New Nintendo 3DS core. Not started yet.

Artemis (Sailor Venus's guardian cat and mentor, Luna's counterpart) — see [`Overview_and_Architecture.md#core-and-component-naming-scheme`](../../../../Docs/EmuSen%20Manual/Overview_and_Architecture.md#core-and-component-naming-scheme) for the full core naming scheme.

**Open question, not yet decided:** whether the 3DS and New 3DS are different enough hardware (the New 3DS adds a second analog stick, extra shoulder buttons, and a faster CPU with more RAM) to warrant two separate cores rather than one — following the same test applied to `MercuryRT - GB` for GB/GBC, where an extension of the same CPU and memory map stays one core.
