# Artemis (Nintendo 3DS / New Nintendo 3DS)

Reserved for a future Nintendo 3DS / New Nintendo 3DS core. Not started yet.

Artemis (Sailor Venus's guardian cat and mentor, Luna's counterpart) — see `Man pages/EmuSen_Core_Naming_Scheme.md` for the full core naming scheme.

**Open question, not yet decided:** whether the 3DS and New 3DS are different enough hardware (the New 3DS adds a second analog stick, extra shoulder buttons, and a faster CPU with more RAM) to warrant two separate cores rather than one — the same question `Mercury - GB-GBC/` faced for GB/GBC, settled there as *one core* on 2026-08-04 on the reasoning that an extension of the same CPU and memory map is not different hardware. The same test applies here.
