# Jadeite (Sega Game Gear)

No crate lives here. The Game Gear is a system of Endou's library (decided 2026-10-19, `Endou_Plan.md` §2.2): its VDP is
a variant of `Beryl-HW/beryl-sms-vdp` and its LCD, I/O and boards are Endou's module `gg`, in
`EmuSen/Cores/Sega/Endou - Master System/src/gg.rs`. The name Jadeite names that module and its record pages,
`Man pages/Hardware/Sega/Jadeite - Game Gear/` (the build record `Jadeite_Native.md`). This folder is kept so that
`EmuSen/Cores/` and `Man pages/Hardware/` keep the naming scheme's places.

See `Man pages/EmuSen_Core_Naming_Scheme.md` for the full core naming scheme.
