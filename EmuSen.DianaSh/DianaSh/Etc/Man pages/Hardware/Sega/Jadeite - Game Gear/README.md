# Jadeite (Sega Game Gear)

The Game Gear's module of Endou, the Master System core (`EmuSen/Cores/Sega/Endou - Master System/`, its `src/gg.rs`),
and its record pages. *Decided 2026-10-19* (`Endou_Plan.md` §10 Q1): the Game Gear is a system of Endou's library, its
VDP a variant of Beryl's `beryl-sms-vdp`, the name Jadeite kept for the module and these pages; there is no separate
`EmuSen/Cores/Sega/Jadeite - Game Gear/` crate. The plan for it is `Endou - Master System/Endou_Plan.md` §2 and its §7
rows J1 to J3 and JL; its disputes are in `Endou - Master System/Endou_Disputes.md`, from D-21.

- [`Jadeite_Native.md`](Jadeite_Native.md) — the build record, from stage J1 (2026-10-20): the system `gg` in
  development and the Game Gear as a console, GG mode's window in 12-bit colours, a Master System cartridge's picture
  shrunk onto the LCD as the documents and the photographs they report describe, the two pieces of J2 that games showed
  were needed first, the gate against the references with the tester's six games, the seeded faults, and the questions
  before J2.

See `Man pages/EmuSen_Core_Naming_Scheme.md` for the core naming scheme, and `Man pages/Hardware/README.md` for how this
documentation set is organized.
