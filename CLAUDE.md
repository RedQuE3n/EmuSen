# Internal nomenclature

Internally to this project, the codename **WiseMan** refers to the AI
coding assistant (Claude) used to develop parts of this codebase. Where
a human-facing label is needed for branches, changelists, or other
project artifacts going forward, prefer `WiseMan` over `claude`.

Note: branches auto-generated by the hosting platform for a given
session (e.g. `claude/<slug>`) are named by that platform's own
tooling, not by anything in this repository, so this convention
applies to naming done from within the project itself rather than to
that automatic prefix.
