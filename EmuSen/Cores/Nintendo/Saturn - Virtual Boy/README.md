# Saturn (Nintendo Virtual Boy)

Reserved for a future Virtual Boy core. Not started yet.

Outer Senshi codename (Nintendo's Inner Senshi lineup - Moon/Venus/Mercury/Mars/Jupiter - covers the mainline consoles; Saturn/Uranus/Neptune/Pluto cover the less conventional/experimental hardware). Sailor Saturn is the Guardian of Death and Destruction — a deliberate, tongue-in-cheek pairing with the Virtual Boy, infamous for causing headaches, eye strain, and nausea in real players.

See `Man pages/EmuSen_Core_Naming_Scheme.md` for the full core naming scheme.
